# 🍽️ ELVORA — Food Delivery Web App

> **Exceptional food, wherever you are.**

ELVORA is a modern, responsive food-delivery web application designed to make discovering, ordering, and tracking food simple and engaging.

The project combines **real-world food-delivery functionality** with a clean, professional interface, interactive experiences, personalized recommendations, offers, and live order tracking.

---

## ✨ Overview

ELVORA allows users to explore restaurants and dishes, search and filter food, customize their orders, apply coupons, complete checkout, and track deliveries.

The application is designed with a **premium visual style while keeping the experience practical and accessible for everyday food ordering**.

From discovering a meal to watching the delivery arrive, ELVORA brings the complete ordering journey into one platform.

## 🚀 Core Features

### 🍔 Food Discovery

* Browse restaurants and food items
* Explore different cuisines and categories
* Mains, Drinks, Desserts, Combos and Fast Selling
* Popular and recommended dishes
* Recently viewed items

### 🔍 Search & Filters

* Search by dish, restaurant or cuisine
* Filter by:

  * Cuisine
  * Price
  * Rating
  * Delivery time
  * Distance
  * Vegetarian / Non-Vegetarian
  * Offers
* Sort by recommended, fastest, rating and price

### 🛒 Smart Cart

* Add and remove food items
* Change quantities
* Customize dishes
* Add special instructions
* View price breakdown
* Suggested add-ons
* Automatic total calculation

### 🎟️ Offers & Coupons

* Dedicated offers section
* Coupon code application
* Minimum-order validation
* Automatic savings calculation
* Eligible-offer suggestions
* Examples include:

  * `WELCOME250`
  * `TWO20`
  * `DELIVERYFREE`
  * `SWEET100`

### 📍 Location & Delivery

* Saved addresses
* Home, Office, College and other locations
* Delivery instructions
* Map-based location interface
* Estimated delivery time

### 💳 Checkout & Payments

* Multi-step checkout
* Address selection
* Order summary
* UPI
* Credit/Debit Card
* Net Banking
* Wallet
* Cash on Delivery
* Secure payment interface

### 🗺️ Live Order Tracking

* Interactive delivery tracking interface
* Restaurant location
* Customer destination
* Delivery partner location
* Route visualization
* Live ETA
* Distance remaining
* Order status timeline
* Delivery partner information
* Call / Chat / Help options

### 🤖 ELVORA Concierge

An intelligent food assistant that helps users discover what to order.

Users can ask for recommendations such as:

* "Something spicy but not too heavy"
* "Best food under ₹300"
* "Recommend a vegetarian meal"
* "What's popular?"
* "Show me today's offers"

The assistant provides recommendations based on the available restaurant and menu data.

### ❤️ Personalization

* Favourite restaurants
* Favourite dishes
* Order history
* Reorder previous meals
* Personalized recommendations
* Recently viewed items

### 🔔 Notifications

Users can receive updates for:

* Order confirmation
* Food preparation
* Delivery updates
* Offers
* Payments
* Restaurant updates

### 🎮 Play While You Wait

ELVORA includes a dedicated interactive waiting lounge with **three mini-games**:

1. 🥕 **Catch the Ingredient**
   Catch the correct ingredients while avoiding the wrong ones.

2. 🧠 **Food Memory**
   Match food cards with the fewest moves possible.

3. 🍱 **Build Your Plate**
   Create a balanced plate using different food categories.

The games section uses a more colorful and playful visual style while the rest of the application maintains ELVORA's professional design language.
